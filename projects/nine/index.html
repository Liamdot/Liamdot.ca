Nine

made September 2026

Nine squares. Pick one and it opens into nine more, four times over. At the bottom of every path is a spot for one short message.

How it works

  • There are 6,561 spots, and each one holds a single message
  • Find an empty one and it's yours to write
  • Brighter squares have more messages hidden below them
  • Every spot has its own link, so you can send someone straight to it
