Name that Number

made September 2026

A tiny neural network trying to read your handwriting.

How it works

  • Your drawing is shrunk to 28×28 pixels, like the digits the network learned from
  • Each pixel feeds into 32 neurons, then 16, then 10 — one for each digit
  • Brighter neurons are more active. Green lines push the next neuron up, red lines push it down
  • Hover a neuron in the first hidden layer to see the pattern it looks for

It learned from 60,000 handwritten digits (the MNIST dataset) and gets about 96% of new ones right.
