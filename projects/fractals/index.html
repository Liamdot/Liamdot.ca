Fractal Explorer

made September 2026

Shapes made from one tiny formula, repeated until it either flies off to infinity or doesn't. The colours show how fast each point escaped.

Controls

  • Scroll or pinch to zoom
  • Drag to move around
  • Double-click to zoom in (Shift to zoom out)
  • Right-click the Mandelbrot set to see that point's Julia set
  • + / −, arrow keys and R (reset) work too
